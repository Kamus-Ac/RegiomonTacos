# RegiomonTacos

A 3D cooking simulation game inspired by Monterrey's street taco culture.

Take the role of a taquero, prepare orders, manage your kitchen, serve customers, and try to keep up with their demands.

Developed with **Unity** and **C#**.

## Gameplay

RegiomonTacos is a first-person cooking game centered around preparing and serving tacos.

Player interact with different kitchen stations, collect and prepare ingredients, assemble orders, and deliver them to customers. As the taco stand gets busier, players must manage their time and keep their customers satisfied.

### Features

* First-person 3D gameplay
* Interactive kitchen stations, like Overcooked.
* Ingredient and recipe system
* Customer orders
* Customer AI and navigation
* Customer satisfaction states
* Order validation
* Multiple cooking stations
* Interactive UI
* Dynamic customer generation

## Technologies

* Unity
* C#
* Unity NavMesh
* Unity Input System
